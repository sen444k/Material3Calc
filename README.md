# Material3Calc

Calculator application for Android 2.2 (API 8) with Material 3 user interface.

## Features
* **Android 2.2 Compatibility:** Runs on API level 8 devices and emulators.
* **Modern UI:** Implements Material 3 design guidelines.
* **Ripple Effect:** Touch feedback animation for buttons.
* **Advanced Mode:** Additional extended mathematical operations.
* **History:** Tracks and displays previous calculations.
